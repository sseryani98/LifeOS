- Shell entry is `http://localhost:4004/` (not /shell/webapp/index.html, which 404s). List hashes are `#/{EntitySet}List` since D-096 (`#/TransactionsList`, `#/IssuersList`); record hashes stay `#/Transactions(ID=…,IsActiveEntity=true)`. Or click side-nav items with `.sapTntNLI:has-text("...")`. The Transactions group must be expanded first (click its expand chevron).
- Object-page Edit creates a CAP draft; briefs often forbid drafts, so edit mode is unreachable by design. Say so instead of skipping silently.
- Console always has ~11 baseline errors per app (Component-preload.js 404, i18n_en*.properties 404, lrep/flex 404) = dev-server noise, not findings. Real defects show as extra errors on a nav click.
- Reusable probe: loop `body *` with offsetWidth, collect non-0 borderTopLeftRadius (excluding 50%) and blue-dominant colours (b > r+50). Returned empty on a clean theme pass.
- Playwright file output (console filename) must be inside `c:\Projects\Life OS` or its `.playwright-mcp`, not the scratchpad.
- No hover tool is loaded: to read `:hover` styles, `click` a harmless toggle (the DynamicPage pin button `[id*=pinBtn]`, click twice to restore) then evaluate `button:hover`. Buttons that open dialogs/file choosers lose or wedge hover. For the FileUploader, read CSSOM hover rules instead of clicking (file chooser blocks the MCP).
- Admin apps stay mounted hidden after nav, so `button:has-text("Go")` matches 9 — target by full id (`...FilterBar::Transactions-btnSearch`).
- Hash deep links (`#SimpleFINConnections`, `#/SimpleFINConnections`) never navigate on load or hashchange; the D-005 deep-link half is unverifiable on screen (D-014 area).
- Every admin nav click logs `TypeError: o.storeInnerAppStateAsync is not a function` (+1 per click); baseline-ish, tied to D-014.
- Stock Horizon `--sapContent_LabelColor` `#556B82` (cool slate) still colours field labels/object subtitle; THEME.md does not override it. 5.3:1 on Parchment, passes AA, only a warm-theme tint gap.
- Port 4004 may serve a stale pre-change backend (missing new actions). Own instance: `PORT=4010 CDS_TYPESCRIPT=true NODE_OPTIONS="--import tsx" npx cds-serve --profile development` (plain `cds-serve` loads no `srv/*.ts` handlers: "has no handler for ..."). Dev profile = in-memory SQLite, empty; kill it by port when done.
- Seed transactions via action `POST /service/transactionSvcs/saveCsvImport` (CsvSaveRow list); direct POST/PATCH of Transactions drops fields, so draftActivate fails on `source`. Then `splitTransaction` action for a recurring split.
- Shell side-nav: `el.click()` from evaluate does nothing; dispatch pointerdown/mousedown/pointerup/mouseup/click. Transactions group starts collapsed (selected item inside is not highlighted).
- Dialog buttons (Split, Apply Categories) showed `hasListeners("press") === false` and Cancel did not close (2026-11-04, both dialogs); close via `sap.ui.getCore().byId(...).close()` to continue. Check this first on any dialog review.
- The Playwright browser is shared with other agents: mid-run it jumped to another port (`localhost:4033`) and `history.back()` lands there. Re-`navigate` to your own port after every back; prefer in-app nav clicks.
- Transaction List default filter "Last 7 Days" ends yesterday, so rows dated today are hidden (empty list, not a bug). Seed `postedAt` 2-6 days back. Dialog Cancel closed fine on 2026-11-05 (the old `hasListeners` gotcha no longer reproduced).
- Dev profile has no Vendors; `POST /service/transactionSvcs/Vendors {"name":..}` works for seeding. Semantic Information blue (`#0064D9`, user-corrected ObjectStatus) is allowed by THEME.md §3.3; do not file it.
- Escape closes only the topmost popup (a ComboBox dropdown), not the dialog under it; the dialog's block layer then intercepts clicks. Check `sap.ui.getCore().byId(dialogId).isOpen()` before the next click. `.sapMDialog` reports `offsetParent` null even when open, so filter on `isOpen()`, not visibility.
- Seeded split via `splitTransaction` needs `mySharePct` OR `myShareAmount`, never both. Object-page header is already expanded on open; list header expand button is `button[id$="DynamicPageTitle-expandBtn"]`; filter value-help icons are `[id$="FilterField::<prop>-inner-vhi"]`.
- Dialog buttons need a real `browser_click` by id (`SplitDialog--idSaveSplitButton`, `ApplyCategoriesDialog--idApplyCategoriesConfirmButton`/`idCancelApplyButton`); `el.click()` from evaluate fires no press (no refusal toast appeared). Fill inputs via `el.value` + dispatch `input`+`change`. Refusal/warning MessageBox OK ids are `__mbox-btn-N` with N incrementing; list them by text first. Button focus rings (`.sapMBtnInner::before`) compute 6px radius, a leak the sweep catches only when a button is focused.
- Seed recipe that works on a fresh dev profile: POST 3 Vendors, then `saveCsvImport` with `cardInstance_ID` `a1b2c3d4-0023-4000-8000-000000000001` (seeded CardInstance exists) and rows `postedAt` 2-5 days back.
- Apply Categories dropdowns: ComboBox ids `idVendorsApplyComboBox`, `idPurchaseTypesApplyComboBox`, `idEarningCategoriesApplyComboBox`; read items via `getItems()`.
- Journey seed (`--profile development,journey`) has rows dated Sep-Oct 2026 and the default filters (last 7 days + uncategorized) hide them. Clear both in one evaluate: `sap.ui.getCore().byId("com.financialplanner.transactions::TransactionsList--fe::FilterBar::Transactions::FilterField::postedAt"|"...::categorizationStatus").setConditions([])` then `.getParent().triggerSearch()`. In-app `location.hash = "#/Transactions(ID=...,IsActiveEntity=true)"` DOES navigate once the shell is loaded. Discard Draft on an untouched draft closes with no confirm popover; after edits a popover `Discard` button appears.
- Journey seed ids: Transactions `7e5d0002-0000-4000-8000-00000000000{1=Oct,2=Nov,3=Sep}`; Nov has no split (Split dialog pre-fills the recurring suggestion 20 / 24.00), Oct+Sep have splits. Amount-only split: POST `splitTransaction {transactionId, myShareAmount}`. Header ObjectStatus inner span is `__statusN-text`; list-row clones carry `clone` in the id. Display-mode empty % reads "–" plus hidden "Empty Value" a11y text.
- Round 9 (2026-11-05): ToolSearch for type/press_key finds nothing; the briefs asking for real keystrokes cannot be met, so say so up front. The `hasListeners` and FloatType first-open gotchas below no longer reproduce (D-082 fixed). Outer `<button>` computes Arial 13.3px; the inner `.sapMBtnInner` is DM Sans, so do not file it. `f72` sweep hits on empty flex/hidden containers are noise.
- No `browser_type`/key tool is exposed. Drive dialog/object-page inputs with `ctl.setValue(v); ctl.fireChange({value:v})` (ids `SplitDialog--idMySharePctSplitInput`, `...idMyShareAmountSplitInput`, object-page pct is `__input0`). Dispatching DOM `input`/`change` events lags one edit behind (recompute used the previous value) - false data. Object-page amount edit via fireChange did NOT clear the % (dialog does): unverified with real keys.
- Single-row selection for Split: mdc table `._oTable.removeSelections(true); ._oTable.setSelectedItem(getItems()[n],true,true)`; a bare checkbox click hit select-all. Dialog Cancel ids: `SplitDialog--idCancelSplitButton`. `FloatType` "failed to load" console error appears once on the first Split-dialog open of a session (render still fine).
- Round 11 (2026-11-05): own server on `PORT=4051` with `--profile development,journey` worked first try. Dialog contrast: `.sapMDialog` and its scroll container are transparent, so walk ancestors for the first opaque bg (`.sapUiFormBackgrTransluc` = `rgb(250,250,248)`); label `rgb(107,98,89)` = 5.71:1. Display-mode forms have no `<label>` elements, so measure Details groups by screenshot. At 1920 the ObjectPage section/sub-section headings sit at x=305 while the cards sit at x=289 (equal at 1440); the anchor-bar expand icon computes 4px radius.
- Round 12 (2026-11-05): own server `PORT=4061 ... --profile development,journey` fine. Measure ObjectPage heading left via a Range on `.sapMTitle` (the `.sapUxAPObjectPageSubSectionHeader` box is at 257 incl. padding); 305 = 305 at 1920 after D-090. Anchor-bar radii: focus every descendant, then read `::before/::after` too (empty after D-091). Header ObjectStatus (`__statusN`) read `state None`/black on a fresh deep-link load of the Oct row (criticality virtual binding unresolved) but `Information` after cycling records via hash: check `getState()` not colour, and repeat before filing. Amount-only seed: POST `splitTransaction {transactionId, myShareAmount:10}` on Sep row (...0003). Pre-existing `db.sqlite` (Apr 2026) in the module root is not yours.
