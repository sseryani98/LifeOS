gate-runnerhaikuRuns the build gate (tsc, lint, test, cds build) and reports raw results. Classifies each failure so the workflow can route repair to the right model tier. Never fixes anything.
implementeropusBuilds the source for a story until the gate is green, working against tests it may not edit. Also marks the sprint board at handoff. Never commits.
quality-revieweropusRead-only code reviewer for the code-quality workflow. Finds judgment defects and argues about them, but cannot modify the tree. Use for any review stage that must not apply its own findings.
smoke-testersonnetDrives a built UI in a real browser and reports what it observed. Read-only against the tree — it validates, it never fixes.
spec-writeropusTurns a completed workshop record into a lean SPEC-nn file — following the DESIGN_WORKSHOP template exactly, logging decisions, validating the Definition of Done. Writes in an isolated context so the interview never competes with document production. Does not interview; if the record has a hole, it returns a gap rather than inventing.
test-authoropusWrites the failing tests for a story from its business rules and FUTs, and later raises coverage to threshold. Owns the test tree and writes nothing outside it.
ux-testersonnetReviews a story's built pages against the Design System, Theme, and Information Architecture in a real browser — contrast, theme adherence, wording, and page-to-page consistency. Read-only against the tree; it reports, it never fixes.
